# dsh-plugin-rollout-scout

[English](./README.en.md) | 中文

给 DeepSeek Harness 用的「灰度模型钓鱼器」。当供应商灰度发布更强的对话模型时，它可能只在随机新会话里出现。本插件并发地开启一批短探测会话，**实时**读取它们的思维链，靠措辞特征快速判断：

- 反方（旧模型）强特征：**"Let me"**、**"We need"**，按 **双倍权重** 计入。
- **思维链为中文** 时无视分数直接丢弃（可开关，默认开启）。
- 正方（灰度模型）特征：**"I'm"**、**"I need"**、**"For"**。

### 置信度分数

每个探测都有一个 0–100% 的「灰度置信度」：

```
分数 = (正方加权数 + 1) / (总加权证据 + 2)
```

加一的先验（拉普拉斯平滑）意味着 **证据少时分数停在 50% 附近**，不会因为一个偶然的词就给出自信的判断。举例：

| 证据 | 分数 | 含义 |
| --- | --- | --- |
| 无 | 50% | 无法判断 |
| 1 × "Let me" | 25% | 立即丢弃 |
| 1 正 / 10 负 | 15% | 明显不是灰度 |
| 3 正 / 0 负 | 80% | 保留 |

低于 `低于此分即丢弃`（默认 0.35）→ **立即中止该轮并丢弃**（不浪费额度跑完）；高于 `高于此分即保留`（默认 0.7）→ **放行跑完并保留**。两者都要求先累计到 `最少证据量`（默认 2），因此单个词不会决定结果。

> ⚠️ 这些短语特征是启发式的，并非官方判据，只反映不同模型的思维链风格差异。权重与阈值都可调。

## 界面

侧边栏底部有「灰度侦察」入口，点开是 **整屏控制台**：

- 左栏：**探测提示词**、**模型**（默认 V4-Pro / High）、**并发数**、**存放目录**，以及评分阈值与开关（`命中一次后停止`、`思维链为中文时立即丢弃`、`自动删除旧模型会话`）。没有探测数量上限，会一直探测到你停止为止。
- 右栏：顶部统计（已发起 / 进行中 / 已保留 / 已丢弃 / 最高分），下方是 **按置信度排序** 的探测队列（高分在上），分数变化时行会 **动画滑到新位置**；被丢弃的探测会 **移出队列**（仍计入「已丢弃」）。每行带 **分数条**（标出两条阈值线）、命中的短语（正/负分色）、状态与思维链预览；**点击任意一行即可打开该会话**。
- 运行时 **开始** 变为 **停止**：停止只是不再发起新探测，进行中的会各自跑完判定。**强制停止** 会额外中止所有进行中的会话。**清空已结束** 清理历史。

界面跟随 DSH 显示语言（中文 / English）。

## 工作原理

- 宿主端提供 `/rollout-scout` 接口，用 `ctx.agents.create`（不带 seed）凭空创建全新会话，用 `installModelSelection` 设置模型与思考强度。
- 订阅该会话作用域内的 `session/event`，读取 `assistant/chunk` 里的 `reasoning-delta`（思维链增量），逐字累计并即时分类。
- 命中旧模型特征时调用 `agent.cancel` 中止当前轮；命中新模型特征时放行至 `turn/end`。
- 所有探测会话都创建在你指定的目录下（作为一个工作区），可选自动删除判为旧模型的会话。

## 安装

```
dsh plugin add dsh-plugin-rollout-scout
```

安装后重启 DSH（宿主端随服务器加载）。

## 兼容性

界面挂在全局 `shell.overlay` 层，不与任何会话内插件冲突；界面跟随 DSH 显示语言。与 [dsh-plugin-smooth-stream](https://github.com/SpookySandwich/dsh-plugin-smooth-stream)、[dsh-plugin-smooth-motion](https://github.com/SpookySandwich/dsh-plugin-smooth-motion)、[dsh-plugin-message-tree](https://github.com/SpookySandwich/dsh-plugin-message-tree) 同族共存。
